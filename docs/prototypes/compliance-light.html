关于本站

这是什么

一个按年份浏览世界历史的地图册：左侧时间轴、地图上的政区与事件、点开的人物与战争卡片。纯静态站点，无账号、无追踪。

「依据：模型整理」是什么意思

人物生平、人物评价、语录、战争进程与分析、政区事实，由语言模型依据公开资料整理，未经逐条核验。卡片上显示「依据：模型整理」即指此类内容；它表示"内容是整理的，不是从某一本书里逐字摘出来的"。

「依据：文献 N 项」是什么意思

该卡片有 N 项具名来源，可在卡片内的「依据」列表中逐项展开。能点开的给链接；只能给书名的标明"仅有文献名"。其中属于研究者观点转述的，会单独标注「转述」。

哪些地方仍然缺出处
  • 语录与他人评价的逐条出处仍在补全，未补全的展开时显示「出处待补」。
  • 政区的人口、族群、语言等数值为估算，标「约」，不作为统计引用。
  • 事件卡暂未挂条目级链接，只保留文献名。
