# 战争与人物数据完整性审计

> 审计日期：2026-11-15 · 结论口径：只认命令输出，不靠印象
> 可复跑：`node scripts/data/audit-profiles.mjs`（`--json` 输出机器可读缺口）
> 本轮补充用到的模型：`deepseek-v4.1-flash`（OpenCode Go 的 OpenAI 兼容端点），凭据仅经 `OPENCODE_API_KEY` 环境变量传入，**未写入任何文件**。

---

## 1. 结论先给

**结构完整度很高，但「完整」和「可信」是两件事。**

- 补全前：战争 94 场、人物 414 位，索引与档案一一对应，核心字段（名称、年代、概述、交战方、过程、结果）无缺失，2,170 个生平站点的中英描述 100% 齐全。
- 但存在三类真实缺口：**可选字段缺失**（23 场战争无 `sources`）、**分类字段未统一**（410 份人物档案缺 `era`）、**通识条目未收录**（4 位帝王、2 场鸦片战争），以及一个**实质错误**（丹东档案实体错认）和 5 处**编码损坏**。
- 补全后：战争 96 场、人物 418 位，`npm run validate:data` 仍是 **ERROR 0 / WARNING 0**。

需要强调：`sources` 等由模型补写的字段是 **C 级（未核验）** 内容，完整度提升不等于准确性提升。分级口径见 [`开源说明.md`](./开源说明.md) §5，机器可读清单见 [`ai-generated-fields.json`](./ai-generated-fields.json)。

## 2. 补全前扫描结果

| 项目 | 战争 | 人物 |
|------|------|------|
| 索引 / 磁盘档案 | 94 / 94，孤儿 0 | 414 / 414，孤儿 0 |
| 生平站点 | — | 2,170，中英描述齐全 2,170（100%） |
| 必需字段缺口 | `sources` 23、`warProcess.phases` 2 | `points` 1、`birth` 2、`death` 18 |
| 可选字段未提供 | `alternativeNames` 15、`relatedWars` 19、`theaters` 1、`neutralParties` 38 | `era` 410、`othersBy` 3 |
| 时间跨度 | -499 ~ 2023 | 出生年 -2254 ~ 1969；1800 年后出生 246 位（偏近现代） |

对「缺口」的两个必要澄清：

- **18 位人物缺 `death` 不是错误**：其中多数是在世人物（比尔·盖茨、鲍勃·迪伦、简·古道尔等），其余是生卒本就不详的古代人物。给在世人物编造卒年反而是错误，因此**不补**。
- **`neutralParties` / `relatedWars` 空是合法值**：很多战争没有中立方或明确关联战争。审计脚本因此把它们归为「可选字段」，只统计覆盖率，不当作数据问题。

## 3. 查到的实质错误（比字段缺口更重要）

| 问题 | 证据 | 处理 |
|------|------|------|
| **实体错认** | `people/profiles/dan-dong.json` 把「丹东」写成「中国近代政治家」，编造「甲午战争期间某些决策导致中国失败」，`nameEn` 为地名拼音 `Dandong`，`points` 为空 | 按通行史实整份重写为法国大革命人物 **Georges Danton (1759–1794)**，补 3 个生平站点，同步索引；记入 `ai-generated-fields.json` 的 `fixes` |
| **UTF-8 字节损坏** | `events/1327.json`、`1328.json`、`1334.json`、`ne/polity_descriptions.json` 共 5 处连续 U+FFFD，如「社□和人口危机」「控□」 | 按上下文补回单字（社会 / 控制 / 中亚 / 并 / 王国）；修复脚本按「连续替换字符 = 1 个损坏汉字」处理，并在写盘前校验 JSON 合法 |
| **来源字段缺失** | 23 场战争 `sources` 为空 | 由模型补全为「建议阅读书目」，**明确标注未核验**，不得作为文献引用依据 |

修复过程中还发现一个工具陷阱并已修正：一个损坏汉字会留下 **2–3 个连续 U+FFFD**，若按单个替换字符逐个补字，会得到「控制制制」「从中中亚」。脚本现已按连续序列折叠处理。

## 4. 本轮补充内容

> 关于 `sources`：模型给出的书名可能不是精确书名（例如泛称的「某某战争史」）。它们是**推荐阅读线索**，不是已核验的参考文献。需要引用时请自行核对版本与页码。这也是 `开源说明.md` 把 C 级内容单列的原因。

### 4.2 条目级（新增 6 份完整档案）

| 类型 | 新增 | 依据 |
|------|------|------|
| 人物 | 汉武帝、唐太宗、朱元璋、康熙帝 | 通识名单中确认缺失的中国古代帝王 |

每份新档案都按现有 schema 生成并校验：人物至少 3 个带坐标的生平站点、评价中立；战争 2–3 个阶段、4–5 场带坐标的战役、时间线 4–5 条。同步更新了 `index.json`、`war_locations.json`（战役坐标中位数）与 `people/coords.json`。

### 4.3 明确不自动生成的内容

写入 `scripts/data/generate-new-profiles.mjs` 的收录边界，也是开源时解释争议的依据：

- 近现代政治人物的评价
- 在世人物的评价

- 进行中冲突的实时结论与立场判断

释迦牟尼、耶稣等虽在通识名单里，但按此边界不纳入。已复核「达芬奇」并未缺失，只是写作「列奥纳多·达·芬奇」（带间隔号），属于早期子串匹配的误报，已从期望名单中修正。

## 6. 覆盖面：够不够？

对个人学习定位而言，**够用**：96 场战争覆盖从希波战争到 2023 年的主要冲突，418 位人物覆盖古代到当代的主要文明，事件数据 17,998 条提供了主时间线。

但它是**策展式抽样，不是全量名录**：没有宣称「所有重要人物/战争都在」，人物分布明显偏近现代（1800 年后出生占 59%），非西方古代人物偏少。这个偏差本身值得在 README 里说明，而不是靠继续生成更多条目来掩盖——每新增一份 AI 档案，就多一份需要核验的内容。
