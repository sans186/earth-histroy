# 人工审查计划（UR-013）

> 本文件只定义人工审查的范围、时间盒、条目清单与记录模板，不代替实际审查。
> 审查期间对 `public/` 只读核对，不改数据；发现问题按 `CONTRIBUTING.md` 的勘误流程另行走 Issue / PR。

## 1. 预算与时间盒

总预算：**20 小时**（人工审查预算，不是开发工时）。三项合计不超过 20 小时，任一方向超支即停止并把剩余项登记为「未人工复核」，不静默扩大范围。

| 块 | 范围 | 预算 | 条目数 |
|---|---|---|---:|
| A | 争议区 / 国界 | 8 h | 59 |
| B | 在世人物 | 7 h | 15 |
| C | 进行中冲突 | 5 h | 6 |
| — | 合计 | **20 h** | **80** |

清单口径：以 2026-11-21 仓库现状为准；条目数按「可单独记录一条结论的最小单元」计（同一政区的逐段切片按切片数计）。

## 2. 审查范围

- 只读核对 `public/` 中的数据文件与 `scripts/data/` 中的修正脚本，配合 `docs/开源说明.md` §6.2 / §6.3 的口径。
- 每块按下文清单逐条记录，不做事后抽样扩围；清单外的内容（全量 415 份人物档案、97 份战争档案、5227 个事件文件）不在本轮预算内。
- 审查结论只写入本文件的记录表，不直接改数据；需降级或隐藏的条目先记录，再按勘误流程处理。
- 涉及边界、命名与主权表述时，一律按 `docs/开源说明.md` §6.2：历史边界为学术重建，不作主权立场；台湾、香港、澳门是中国不可分割的一部分；现代国界图层仅作地理参照。

## 4. 完成标准

**A 块**

- 59 条全部有结论，逐条注明「保留 / 降级 / 隐藏」。
- A1-1 的运行时折叠、A2 的 7 条线要素不绘制行为均实际核对过一次。
- 所有结论不构成主权裁定；表述与 `docs/开源说明.md` §6.2 一致。

**B 块**

- 15 条全部有结论与来源；11 条在世人物确认无评价、语录与结局性判断。
- 生卒字段与权威来源逐一比对；不一致的登记为待勘误，不当场改数据。
- 生卒不详的 4 条确认未被当作在世人物展示。

**C 块**

- 6 条全部有结论；5 份战争档案的 `outcome` / `legacy` 已核对，不出现胜负分析与实时结论。
- C-6 缺口给出明确处置意见（维持不收录或列入后续需求），并写明理由。

**通用**

- 每条记录包含审查人、日期、条目、结论、来源、是否降级/隐藏。
- 超预算即停：未完成项统一标记「未人工复核」，并在本文件末尾补记剩余量。

## 5. 记录模板

每完成一条即追加一行，不合并批次。

| 审查人 | 日期 | 条目（文件 / ID） | 结论 | 依据来源 | 是否降级/隐藏 | 备注 |
|---|---|---|---|---|---|---|
|  |  |  | 保留 / 降级 / 隐藏 / 待勘误 | 书名、论文、官方资料或数据集链接 | 是 / 否 |  |

约定：

- 「结论」只取四个值：保留、降级、隐藏、待勘误。
- 「依据来源」必须可核验；仅凭印象的结论记「无来源」，不得直接降级或隐藏。
- 「是否降级/隐藏」为「是」时，在备注写明处理方式与后续 Issue 编号。

## 6. 未覆盖内容的处理口径

- 清单外的全部内容统一标注「**未人工复核**」。
- 界面层：`src/components/AboutPage.vue` 的 AI 生成说明段落已增加一行常驻说明（文案键 `about.unreviewedNote`）：除本计划所列条目外，其余内容未人工复核。
- 文档层：本文件与 `docs/开源说明.md` §6.3 的收录边界共同构成对外口径；不新增「已核验」之类无法证明的标注。
- 数据层：本轮不在 `public/` 增删任何标注字段；若后续需要机器可读状态，另立需求，并避免把「未复核」写成「已核验」。
