## 0. 先更正一个前提

「事件里已经在用的维基链接」并不存在。事件卡上那个「搜索 Wikipedia ↗」按钮是**运行时拼出来的搜索页**，不是条目引用：

- 实现：`src/lib/wiki.ts` 的 `wikiSearchUrl(name, 'zh')` → `https://zh.wikipedia.org/w/index.php?search=…`
- 事件数据里的 `sources` 只有 `name` / `type` / `contemporary` 三个键，共 40,860 条，**带 URL 的 0 条**

真正在用条目级引用、可以当样板的是**政区**：Cliopatria 的每个要素都带一个 `Wikipedia` 字段（文章标题），前端用 `wikiArticleUrl()` 拼成 `https://en.wikipedia.org/wiki/<title>`。这条路径才叫"可核验的引用"。

所以本清单的样板不是事件，是政区；事件是否要补，放在文末待确认项里。

### 1.2 现有等级判定已经是"有链接就升级"

`src/lib/provenance.ts` 的 `evidenceLevel()`：

- 有 2 条以上 `http(s)` 链接 → R0
- 1 条 → R1
- 只有文献名 → R2
- 什么都没有 → R3

也就是说：**只要把 URL 填进数据，徽标和等级会自动变，不需要改判定逻辑。**
同样，`appraisalItems()` 已经在读 `evaluation.sources[stance]`，有来源的评价会自动显示、不必开开关——这正是 UR-007 要的接线口，目前只是没数据。

### 1.3 政区瓦片里的标题映射要注意的坑

瓦片名和文章标题不是一一对应：

| 瓦片 `Name` | `Wikipedia` 标题 |
|---|---|
| `Northern Song` / `Southern Song` | `Song dynasty` |
| `(Qing Dynasty)` / `Qing Dynasty` | `Qing dynasty` |
| `Zhou Dynasty` | `Zhou dynasty` |

所以"按名字回填标题"必须以 `Wikipedia` 字段为准，不能拿 `Name` 直接拼 URL。
反过来，`polity_facts.json` 的键本身就有一半以上是标准标题：**1,970 条里有 1,452 条的键可直接命中瓦片标题集合**，其余 518 条（`Aceh Sultanate`、`Adiabene`、`Algeria` 这类）需要单独处理。

## 2. 挂载位置与字段

### 2.1 统一的来源对象

所有位置都用同一个结构，放在数组里：

```json
{
  "kind": "wikipedia | wikiquote | britannica | scholarly | primary | institution",
  "lang": "zh | en",
  "title": "Abraham Lincoln",
  "url": "https://en.wikipedia.org/wiki/Abraham_Lincoln",
  "publisher": "Wikipedia",
  "license": "CC BY-SA 4.0",
  "supports": "生平时间线 1809–1865",
  "accessed": "2026-11-21"
}
```

`supports` 是必填项，写明"这条链接支撑卡片的哪一段"，否则等于把链接挂上去凑数。
政区简介是单条来源，直接用 `source`（对象），不用数组。

### 2.2 逐类挂载表

| 实体 | 文件 | 字段 | 链接类型 | 预计覆盖 | 依据 |
|---|---|---|---|---|---|

| 人物语录·本人 | 同上 | 新增 `quotes.sources.self[]` | 维基语录 / 原始文献（演说、著作） | 415 → 约 150–220 | 只有名句级引文可核验；冷门人物无维基语录页 |

### 2.3 字段写法示例

人物：

```json
{
  "personId": "abraham-lincoln",
  "sources": [
    { "kind": "wikipedia", "lang": "en", "title": "Abraham Lincoln",
      "url": "https://en.wikipedia.org/wiki/Abraham_Lincoln",
      "publisher": "Wikipedia", "license": "CC BY-SA 4.0",
      "supports": "生平时间线 1809–1865", "accessed": "2026-11-21" }
  ],
  "quotes": {
    "self": { "zh": "…", "en": "…" },
    "sources": {
      "self": [
        { "kind": "wikiquote", "lang": "en", "title": "Abraham Lincoln",
          "url": "https://en.wikiquote.org/wiki/Abraham_Lincoln",
          "publisher": "Wikiquote", "license": "CC BY-SA 4.0",
          "supports": "葛底斯堡演说「民有、民治、民享」", "accessed": "2026-11-21" }
      ],
      "others": []
    }
  },
  "evaluation": {
    "supporter": { "zh": "…", "en": "…" },
    "sources": { "supporter": [], "critic": [], "objective": [] }
  }
}
```

战争（把现有混合格式收敛成一种）：

```json
"sources": [
  { "kind": "institution", "title": "美国国防部报告",
    "url": "https://www.defense.gov/", "publisher": "U.S. Department of Defense",
    "supports": "战时兵力与伤亡", "accessed": "2026-11-21" }
]
```

政区事实 / 政区简介：

```json
"sources": [
  { "kind": "wikipedia", "lang": "en", "title": "Abbasid Caliphate",
    "url": "https://en.wikipedia.org/wiki/Abbasid_Caliphate",
    "supports": "政体、首都、宗教、货币", "accessed": "2026-11-21" }
]
```

```json
"source": {
  "kind": "wikipedia", "lang": "zh", "title": "周朝",
  "url": "https://zh.wikipedia.org/wiki/周朝",
  "publisher": "Wikipedia", "license": "CC BY-SA 4.0",
  "revisionId": 0, "accessed": "2026-11-21"
}
```

> `revisionId` 留 0 表示"只到条目级，不锁定版本"；能取到旧版本号时再填，避免摘要与现版本漂移。

## 4. 挂了链接也撑不住的内容

这一节是清单的重点：**不是所有内容都能靠"加链接"变成可核验。**

| 内容 | 规模 | 为什么撑不住 | 建议处置 |
|---|---|---|---|
| 三类立场评价 | 1,245 段（415×3） | 模型撰写的综述，不是任何一本书的原文。挂方纳的条目只能证明"存在这种观点"，不能证明这段文字出自他 | 改写为归属句（"据方纳《The Fiery Trial》一系的研究……"）并挂链接；改不动就保留正文、标"模型整理"，**不计入「文献 N 项」** |
| 他人语录 | 415 段 | 署名 413 条，但文本是转述/改写；且 31 条署名本身是泛称（"历史学家"）或一段说明文字（丹东那条） | 能核到原句的保留并挂链接；核不到的直接删，或降级为"评述"并入评价块 |
| 本人语录 | 415 段 | 名句常有多个中译版本，链接能证"有这句话"，证不了"这个译法" | 保留，挂原文链接并注明译本；无出处的展开时显示「出处待补」 |
| 战争胜负分析 | 96 份 `victoryAnalysis` | 归因分析，无单一来源可指 | 保留，标"分析"；进行中冲突已按现有逻辑隐藏 |
| 战争历史意义 | 96 份 `legacy.significance` | 同上 | 同上 |
| 政区人口 / 族群 / 语言 | 1,970 条 | 历史人口无统计记录，模型推断；挂条目只能证明"条目提过相近数字" | 数值一律加"约"，标"模型整理"，不挂精确来源 |
| 事件 `certainty` / `certainty_note` | 17,998 条 | 模型的史料判断，不是史料本身 | 本轮不动 |
| 政区简介的翻译 | 1,971 条 | 是维基摘要的节译/改写，链接只能证原文，证不了译法 | 挂原文 + 标 CC BY-SA，人工抽查抽样 5% |

三档处置规则（后续所有挂载都按这个走）：

- **A 可核验**：链接能直接对上卡片那段文字 → 挂链接，默认显示，计入「文献 N 项」
- **B 部分可核验**：能对上"观点来源"但对不上"这段文字" → 改写成归属句再挂，仍计入「文献 N 项」但标注"转述"
- **C 不可核验**：纯模型综述/推断 → 保留正文，标「模型整理」，**不计入**「文献 N 项」

## 5. 落地方式

### 5.1 字段与兼容

- 全部是**新增可选字段**：`sources`、`quotes.sources`、`evaluation.sources`（类型已有）、`source`。
- 旧文件不加字段仍然合法，页面回落到现在的行为。
- `src/lib/provenance.ts` 不用改（已支持 string / `{url}` 两种形态）；需要补的只有 `src/types/index.ts` 里的可选字段声明。
- 战争 `sources` 的两种形态收敛为对象，但读取端继续兼容字符串，避免一次性改 96 个文件出错。

### 5.2 生成流程

1. 脚本只生成**候选**：`title` / `url` / `supports` 草稿写到 `.tmp-sources/`，不直接写 `public/`。
2. 人工确认后写回；脚本不覆盖已有字段。
3. 每条写回都必须带 `accessed` 日期，便于以后批量重核。

### 5.3 门禁

新增 `scripts/verify-sources.mjs`，随 `validate:data` 一起跑：

- URL 必须 https，域名限定在 `wikipedia.org` / `wikiquote.org` / `britannica.com` / 机构域名白名单
- `supports` 非空
- 同一实体同一段落不得重复挂同一条链接
- 有 `sources` 但全部为空数组 → 报错
- 可选联网模式：逐条 HEAD 检查 200；离线模式只校验格式，CI/无网时用离线

### 5.4 工作量（按条计，不估算工期）

| 批次 | 自动可生成 | 需人工确认 | 必须改写或删除 |
|---|---|---|---|
| 政区事实（1,970） | 1,452 | 518 | 0 |
| 政区简介（1,971） | 1,452 | 519（含脏键规范化） | 0 |
| 人物档案（415） | 约 380 | 约 380（同名消歧必须人工） | 0 |
| 语录（830） | 约 100 | 约 270 | 约 460 |
| 评价（1,245） | 0 | ≤ 300 | ≥ 945（标"模型整理"） |
| 战争（295 条） | 约 150 | 约 60 | 约 85 |

建议顺序：**政区两组（全自动、见效最快）→ 战争 → 人物档案 → 语录 → 评价**。

### 5.5 回滚

只改 `public/` 与 `src/types`，按批次单独提交；回滚 = revert 对应提交，不动代码逻辑。
