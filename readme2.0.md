## 1. 项目概述

**Earth Historical Timeline** 是一个纯前端、无后端的全球历史时空可视化平台，采用 **微内核 + 插件架构**，以 **CesiumJS 3D 地球** 和 **MapLibre GL 2D 地图** 双引擎驱动，将人类 5000 多年文明史投射到虚拟地球之上。

### 一句话定位

> 让每一个人都能站在太空中，俯瞰人类文明的演进。

### 核心数据

| 指标 | 数值 |
|------|------|
| 时间跨度 | -3100 ~ 2025（5126年） |
| 历史事件 | 10,000+ 条（中英双语） |
| 事件年份文件 | 5,236 个 JSON |
| 历史政区 | 15,690 个（Cliopatria） |
| 人物轨迹 | AI生成人物传记（持续扩充） |
| 现代国家 | 201 个（含国旗/国徽/首都等资产） |
| 支持语言 | 中文 / English |
| 代码规模 | ~4,200 行核心源码 |

### 3.2 技术资产

#### 双引擎渲染架构

```
         ┌──────────────────┐
         │   用户界面层       │
         │  (HTML/CSS/JS)    │
         └────────┬─────────┘
                  │
         ┌────────┴─────────┐
         │   插件管理层       │
         │  (8 个插件模块)   │
         └────────┬─────────┘
                  │
     ┌────────────┼────────────┐
     │                         │
┌────┴─────┐           ┌──────┴──────┐
│ CesiumJS │           │ MapLibre GL │
│  3D 地球  │           │   2D 地图    │
│ (主视图)  │           │  (备选视图)  │
└──────────┘           └─────────────┘
```

| 引擎 | 用途 | 优势 |
|------|------|------|
| CesiumJS 1.123 | 3D 地球主视图 | 沉浸式体验、全球视角、时间动态 |
| MapLibre GL 5.24 | 2D 平面地图 | 低性能设备友好、快速区域浏览 |

#### 微内核 + 插件系统

```
Core (68 行)
├── Store      — 响应式状态容器（pub/sub）
├── EventBus   — 瞬时事件通知
└── Viewer     — Cesium 视图工厂

Plugins (8 个，共 ~3,200 行)
├── map-plugin          — 3D 标记点管理
├── timeline-plugin     — 时间轴滑块与播放
├── filters-plugin      — 分类筛选栏
├── popup-plugin        — 事件详情卡片
├── event-panel-plugin  — 左侧事件列表面板
├── layers-plugin       — 底图/政区/2D3D/语言
├── map2d-renderer      — MapLibre 2D 渲染
└── trajectory-plugin   — 人物轨迹可视化
```

插件间零耦合，仅通过 Store/EventBus 通信。新增功能只需编写新插件并注册。

#### 性能优化体系

| 问题 | 解决方案 |
|------|---------|
| 5,236 个 JSON 文件 | 按需窗口加载（±20年），LRU 缓存 120 份 |
| 15,690 个政区几何 | 世纪分片 + 面积排序 Top 250 + 坐标抽稀 75% |
| 滑块快速拖动 | debounce 100ms + AbortController 取消 |
| 标记/标签过密 | DistanceDisplayCondition + scaleByDistance |
| 地球背面标签 | 点积法向量剔除 |
| 播放模式 | preloadRange() 后台静默预加载 |
| MultiPolygon 溢出 | Generation 计数器防竞态 |
| 2D 事件标记 | 聚类 (Clustering) + 2,000 点上限 + 比例采样 |

**适用功能**：自动巡航播放、录屏、数据引用
